# JavaScript30 — 30 Days of Vanilla JavaScript

A collection of 30 hands-on JavaScript projects built as part of the [JavaScript30](https://javascript30.com/) challenge by [Wes Bos](https://wesbos.com/).

This repository documents my journey toward mastering JavaScript fundamentals through consistent practice, problem-solving, and real-world projects.

## 🎯 Goals

- Strengthen my understanding of core JavaScript concepts.
- Improve DOM manipulation and event-handling skills.
- Develop better problem-solving and debugging techniques.
- Build projects using vanilla JavaScript without frameworks.
- Maintain consistent coding habits and document my progress.

## 📚 My Learning Approach

For each challenge, I follow a simple process:

1. Understand the project's requirements.
2. Attempt to build the functionality independently.
3. Study the tutorial to understand alternative solutions.
4. Refactor the code and add improvements where possible.
5. Document what I learned and push the completed project to GitHub.

My focus is on **understanding how JavaScript works, not simply completing 30 tutorials.**

## 💻 Running the Projects

1. Clone the repository:

```bash
git clone https://github.com/EILIYA-bni/javascript30-challenge.git
```

2. Navigate to a project directory:

```bash
cd javascript30-challenge/01-drum-kit
```

3. Open `index.html` in your browser.

Some projects require browser permissions, HTTPS, or a local development server.
